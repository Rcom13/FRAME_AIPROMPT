# FRAME 错误代码

网站中的错误统一显示在屏幕顶部中央。错误代码由“领域 + 四位编号”组成，便于帮助文档、日志与客服定位同一个问题。

| 范围 | 含义 | 代表代码 |
| --- | --- | --- |
| `AUTH-1xxx` | 登录、权限与维护状态 | `AUTH-1001` 需要登录、`AUTH-1003` 无访问权限 |
| `CFG-2xxx` | 模型连接、API Key、接口地址与模型能力 | `CFG-2002` 凭证无效、`CFG-2008` 能力不匹配 |
| `REQ-3xxx` | 输入、文件、频率与请求校验 | `REQ-3002` 内容过大、`REQ-3005` 文件类型不支持 |
| `GEN-4xxx` | 通用生成任务与服务商结果 | `GEN-4003` 响应超时、`GEN-4004` 额度不足 |
| `IMG-41xx` | 图片输入、生成、查询与下载 | `IMG-4101` 参考图不符合要求 |
| `VID-42xx` | 视频创建、轮询、结果与下载 | `VID-4203` 视频结果暂不可读取 |
| `COMFY-43xx` | ComfyUI 连接、节点、模型与执行 | `COMFY-4303` 节点缺失 |
| `DATA-44xx` | 账户同步与生成历史 | `DATA-4401` 账户配置同步失败 |
| `SYS-5xxx` | 网络、服务器、浏览器与未知故障 | `SYS-5001` 网络连接失败 |

完整代码与自动分类规则以 `app/error-codes.ts` 为准。API 返回错误时应同时提供 `error` 与 `code` 字段；前端本地错误使用 `reportFrameError(message, code)` 上报到统一错误中心。
